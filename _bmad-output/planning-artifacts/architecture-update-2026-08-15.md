# Architecture Update — Evidence-Grounded Physical and Syscall Research

## 1. Authority and Supersession

This is an additive architecture overlay for revised Epics 9–18. The parent
architecture remains historical and authoritative only where it does not
conflict with this document. Approval remains planning-only.

The following earlier decisions are explicitly superseded:

| Earlier decision | Binding replacement |
|---|---|
| May supervised ADFA/LID classifier promoted into the live physical runtime | External syscall models never replace the physical detector. The modalities remain separate until late fusion. |
| May generic stratified 80/20 window split | Split complete official groups, traces, scenarios, sessions, files, or runs before windowing. |
| May promotion by a run ID and runtime threshold behavior | Promotion resolves to an immutable `DetectorBundle.v1` containing weights, preprocessing, schema, calibration, frozen threshold, and runtime identity. |
| Post-consensus OPC UA projection used as SCADA evidence | OPC UA receives a pre-consensus plant/transmitter snapshot and is read by a separate real client. |
| July HAI 20.07 target | Use a pinned, version-specific HAI 23.05 adapter. |
| July custom physical track without synchronized edge syscalls | `PTFP-Custom-v1` contains both modalities from the same runs. |
| July unimplemented Epics 9–16 | Revised Epics 9–18 in the approved 2026-08-15 proposal are authoritative. |
| 4–20 mA as a separate modality or autoencoder as a dataset | 4–20 mA is a representation of the physical modality; an autoencoder is a model. |
| Anonymous executable numeric values | No v2 value starts without evidence classification, unit, provenance, and scope. |

Existing v1 code and artifacts remain append-only `legacy-baseline` evidence.
They are not silently relabelled as v2 evidence.

## 2. Binding Architecture Decisions

The system remains a local modular testbed using Python, Go, MQTT, OPC UA,
MinIO, CometBFT, Docker Compose, Keras, and Torch. The dependency direction is:

```text
versioned domain contracts and scientific policy
  -> application use cases and ports
    -> MQTT / OPC UA / MinIO / CometBFT / ML / capture adapters
      -> composition root and read-only dashboard
```

There are exactly two detection modalities:

1. **Physical instrumentation:** raw electrical evidence at the custom edge,
   deterministic span normalization, signal quality, profile identity, and
   derived engineering representation.
2. **Linux host syscalls:** categorical kernel events generated by controlled
   Linux edge workloads and captured at the kernel boundary.

ADFA-LD and LID-DS are external syscall benchmarks. HAI 23.05 is an external
physical/SCADA benchmark. Only `PTFP-Custom-v1` is synchronized across both
modalities and eligible for fusion claims.

Trust and authority rules:

- only the experiment/control zone writes setpoints or actuator references;
- analytics has no control credential or analytics-to-control conduit;
- physical consensus receives physical observations only;
- OPC UA is a separate pre-consensus supervisory path, not a consensus mirror;
- detector identities cannot read restricted truth;
- the evaluator reads truth only after bundle, threshold, fusion policy, and
  score hashes are frozen;
- the dashboard is presentation-only;
- failure of MQTT, MinIO, OPC UA, capture, models, or dashboard may degrade or
  abort evidence, but never changes the compressor command.

## 4. Physical Signal and Experiment Boundary

### 4.1 Process physics and electrical evidence

The simulator retains temperature, pressure, rotation, and other process state
in engineering units because the process model needs physical semantics. It is
a declared research mock, not a validated compressor digital twin.

Only an `InstrumentProfile.v1` converts process state to the transmitted
electrical signal. At the edge, the received electrical measurement is primary
evidence. For a declared linear 4–20 mA profile:

```text
normalized_current = (loop_current_ma - 4 mA) / 16 mA
engineering_value = LRV + normalized_current * (URV - LRV)
```

The 16 mA span is derived from the sourced endpoints. Quality is evaluated
before clipping, preserving under-range, over-range, and fault evidence. A real
programmable 4–20 mA RPM transmitter profile exists, so rotation does not need
to change to 1–5 V solely because it is RPM.

Raw mA, normalized span, and engineering value are three representations of
one physical modality. The physical detector may use a normalized
current-domain feature projection, while raw mA remains preserved for audit and
quality interpretation. Downstream components may not reimplement conversions.

`InstrumentProfile.v1` owns device/model, electrical endpoints, LRV/URV,
units, conversion direction, applicable quality/fault policy, source locators,
revision, content hash, and approved experiment scope. Missing or incompatible
profiles fail closed for v2 scientific processing.

### 4.2 Experiment and truth

`ExperimentSpec.v1` freezes experiment/run identities, code/dependency/image
identities, parameter and profile hashes, physical and workload schedules,
seeds or input traces, timing policy, expected streams, declared splits,
bundles, metrics, stopping/abort policy, fusion policy, and truth-unlock rule.

The requested 25%–75% variation is a `preregistered_factor` named
`speed_reference_pct` or `capacity_reference_pct`; it is not electrical power
or a universal compressor limit. Under a separately declared linear 0%–100%,
4–20 mA command profile, 25%–75% derives to 8–16 mA. Ramp, dwell, settling,
order, repetition, and safety limits require separate provenance.

`ScenarioTruth.v1` is stored append-only under restricted credentials. Truth,
attack labels, scenario names, and future intervals are forbidden from MQTT
observation payloads, consensus, feature tables, model inputs, detector bundles,
detector scores, and detector-visible dashboard projections.

## 5. Real Syscall Capture Boundary

The project controls or mocks the **Linux edge workload**, not the syscalls.
Acquisition, serialization, MQTT, consensus interaction, evidence writes, and
approved safe deviations cause real kernel calls captured by Sysdig/eBPF.

```text
allowlisted Linux edge workload
  -> real Linux kernel syscalls
    -> collector filtered by host/VM/container/cgroup/process
      -> immutable raw capture segment
        -> canonical categorical events
          -> SyscallEventBatch.v1
```

Existing Mosquitto, MinIO, CometBFT, and ABCI container calls are
infrastructure evidence and cannot substitute for an identifiable edge
workload. Physical and syscall streams use separate topics; syscalls never enter
CometBFT physical consensus.

Two modes are strictly separated:

- `fixture-replay`: schema/window/detector tests only; excluded from formal
  experimental claims;
- `host-capture`: real calls captured at the Linux kernel boundary; the only
  runtime mode eligible for `PTFP-Custom-v1`.

ADFA numeric IDs are never executed, translated into fabricated calls, or given
fabricated timestamps. LID-DS is a benchmark and capture-method precedent, not
a live event source.

On Docker Desktop, the capture boundary is its Linux VM/kernel, not Windows. A
spike must measure attribution, ordering, drops, overhead, and raw-to-canonical
replay. If this boundary is unreliable, formal capture moves to a pinned Linux
VM/host. Collector, kernel, filter, buffer, batch, queue, compression, resource,
and loss-policy values are measured or preregistered—not copied from examples.

## 6. Consensus v2 and Independent SCADA

`ConsensusRoundInput.v2` declares the current-domain comparison basis,
instrument profile, quality policy, schema version, and parameter-evidence
references. It cannot contain syscalls, truth, labels, detector scores, or
fusion decisions.

Same-profile redundant observations may be compared in mA. Cross-sensor
aggregation requires dimensionless, profile-aware residuals. Any weight beyond
the documented electrical span requires applicable device uncertainty,
measured calibration, or preregistration. Legacy scales and trust thresholds do
not migrate automatically.

Consensus v2 is one atomic Python/Go migration: serializer/reference logic,
Go transaction/state/query types, downstream mapping, schemas, and shared
golden fixtures change together. Neither language activates independently.
Historical CometBFT/AppHash state is not rewritten.

The OPC UA writer receives a pre-consensus plant/transmitter snapshot. The
server is separate from the consumer; a distinct adapter reads exclusively
through a real `asyncua.Client` connection over `opc.tcp`. It preserves
`StatusCode`, `sourceTimestamp`, `serverTimestamp`, profile, and experiment
correlation. Current and engineering value are separate analogue nodes; an ML
normalized value, if exposed, uses a research namespace.

Bad, uncertain, stale, missing, mixed-profile, or mis-correlated OPC
observations fail closed for comparison. Tests must prove that consensus-only
changes cannot mutate the OPC source and OPC-only changes cannot mutate
consensus. This proves software-path independence, not physical redundancy from
the simulator.

## 7. Contract Ownership and Invariants

All contracts have stable schema identity/version, canonical serialization
where hashed, strict scientific writers, and semantic invariant tests.

| Contract | Owner and binding content | Forbidden content |
|---|---|---|
| `ParameterEvidence.v1` | Source registry: ID, value, unit, class, source/decision locator, derivation, profile and experiment scope | unresolved or anonymous values |
| `InstrumentProfile.v1` | Profile registry: electrical endpoints, LRV/URV, units, quality policy, source/version/hash | anonymous defaults |
| `ExperimentSpec.v1` | Experiment controller: identities, schedules, hashes, timing, splits, metrics, abort and unlock policy | post-test choices |
| `ScenarioTruth.v1` | Restricted truth writer: scenario/condition intervals and correlation | detector inputs or mutable decisions |
| `SignalObservation.v2` | Acquisition: raw electrical, normalized and engineering values, quality, profile, sequence/timestamps and provenance | truth, labels, detector decisions |
| `ConsensusRoundInput.v2` | Physical consensus: observations, basis, profile, quality policy and parameter references | syscalls, labels, detector/fusion output |
| `ConsensusDecision.v2` | Go state/Python reader: committed result, exclusions, evidence references, version | analytics-to-control commands |
| `ScadaObservation.v2` | OPC client: client-read values, DataValue status/timestamps, endpoint/profile/correlation | a consensus-derived source value |
| `SyscallEventBatch.v1` | Capture: ordered categorical events, workload/host/boot/container/process/thread identity, kernel/collector, sequence/time, drops/quality, raw hash | attack labels or fabricated ADFA time |
| `DetectorBundle.v1` | Model registry: weights, architecture, preprocessing, feature schema, sequence/vocabulary policy, calibration hashes, threshold, score direction, runtime digest | mutable runtime fitting state or truth |
| `DetectorScore.v1` | Detector: bundle/window identity, raw and calibrated score, direction, threshold ID, decision, latency, missingness and quality | truth or attack identity |
| `FusionDecision.v1` | Fusion worker: synchronized score references, frozen policy, missing-modality handling and lineage | raw cross-dataset comparison or truth |
| `EvaluationResult.v1` | Restricted evaluator: frozen score/truth join, metrics, uncertainty and limitations | retroactive model/split changes |
| `ArtifactManifest.v1` | Registry: content/schema hashes, parents, activity/tool/code/runtime/source/license identity | mutable aliases as identity |

`SignalObservation.v2` must correlate experiment, run, round, edge, sensor and
event; preserve source/observed timestamps and clock quality; reference the
exact profile hash; and keep raw, normalized, engineering, and quality fields
mutually consistent. Aggregates and per-edge observations are stored separately.

`SyscallEventBatch.v1` must preserve workload, host/VM, boot,
container/cgroup, process/thread, kernel/architecture, collector/filter,
sequence/time, gap/drop/duplicate, capture mode, and raw segment URI/hash when
available. Numeric IDs remain categorical and require ABI/kernel context.

`DetectorBundle.v1` is atomic and content-addressed. Changing weights,
preprocessing, feature order, vocabulary, calibration data, threshold, or
runtime creates a new bundle. Runtime inference loads the exact bundle, never
fits or recalibrates, and fails closed on mismatch. `DetectorScore.v1` never
contains truth.

## 8. Messaging, Storage, Datasets, and Fusion

Logical topic ownership remains separate:

```text
physical/observations/v2  -> SignalObservation.v2
physical/consensus/v2     -> ConsensusDecision.v2
physical/scada/v2         -> ScadaObservation.v2
host/syscalls/v1          -> SyscallEventBatch.v1
detectors/{physical|syscall}/v1 -> DetectorScore.v1
fusion/decisions/v1       -> FusionDecision.v1
```

Truth is not published on a detector-accessible topic. MQTT identity, source
sequence, deduplication, gap detection, and bounded backpressure are evidence.
Slow storage or analytics cannot block control.

MinIO receives persistent storage, tested restoration, and append-only,
versioned namespaces for experiments, raw physical data, raw syscall segments,
consensus, SCADA, models, detector outputs, fusion outputs, restricted truth,
evaluation, and sources. Keys resolve by experiment/run/stream/segment or
content hash. Every finalized object records content/schema hash, parent
artifacts, code/runtime identity, and source/license metadata. Mutable aliases
such as `shadow` or `active` point to immutable bundles but are not scientific
identity.

Dataset boundaries are binding:

- **ADFA-LD:** offline syscall benchmark; preserve official roles, trace
  identity, archive hash/count evidence, and six attack families; no executable
  replay or continuous treatment of IDs.
- **LID-DS 2021:** offline syscall benchmark and Docker/Sysdig precedent;
  preserve version-specific official schema and groups; use an isolated pinned
  Linux environment where necessary.
- **HAI 23.05:** pinned external physical/SCADA benchmark; preserve native tags,
  units, states/counts, continuity, roles, labels, and checksums; do not convert
  wholesale to mA, append custom data, or call it compressor validation.
- **PTFP-Custom-v1:** synchronized custom physical, independent SCADA, actual
  edge syscall, workload/control, detector-output, and restricted evaluation
  evidence joined by immutable experiment/run/window identity. It is the only
  fusion-eligible evidence source.

The physical branch compares LSTM-AE and GRU-AE with declared baselines. The
syscall branch uses categorical sequence objectives and a transparent
n-gram/STIDE-style baseline. Complete groups are split before windows;
preprocessing fits training only; thresholds calibrate on separate validation
and freeze before truth unlock. No model family is declared superior in the
architecture.

Late fusion consumes compatible calibrated `DetectorScore.v1` outputs from the
same held-out custom runs and explicitly handles missing modalities. Initial
OR, AND, maximum, or unweighted-mean policies require preregistration. Learned
weights are a separate supervised experiment. External ADFA/LID records are
never concatenated with HAI rows, and incompatible raw losses are never fused.

The dashboard only projects immutable evidence, quality, provenance, bundle
identity, limitations, and unlocked results. It cannot import, split, train,
calibrate, promote, fuse, relabel, recompute metrics, or mutate artifacts.

## 9. Security, Migration, Compatibility, and Rollback

Formal profiles use separate service identities and least-privilege MinIO/topic
permissions for control, writers, detectors, promoter, evaluator, truth, and
dashboard. Detector/dashboard identities cannot read truth; analytics cannot
write control. Hashes, pinned dependency/image identities, audit events, and
authenticated transport when traffic leaves the isolated host are mandatory
campaign evidence.

Every affected path advances:

```text
legacy -> shadow -> active
```

- v1 and v2 contracts coexist with explicit version routing;
- v2 may project a v1 compatibility payload through one tested adapter; v1
  consumers never infer missing v2 fields;
- physical v1/v2 dual-publishing preserves correlation and duplicate/gap data;
- consensus v2 uses new transaction/state/query versions without rewriting
  historical state and promotes Python/Go atomically;
- v1 autoencoder artifacts cannot load against v2 features;
- all dataset adapters reject unknown layouts rather than coerce them;
- dashboard readers may tolerate versions but cannot rewrite source artifacts.

Rollback changes a routing or promotion alias to a previously verified
immutable path/bundle. It never deletes or rewrites observations, captures,
CometBFT state, manifests, truth, scores, evaluation, failed runs, or source
archives. A profile, parameter, bundle, collector, filter, contract, or fusion
change during a formal run closes it as `aborted`; resume requires exact
identity verification.

Promotion order is: freeze v1 and golden fixtures; enforce provenance; shadow
Signal v2 and experiment/truth; shadow atomic consensus v2; prove independent
OPC; freeze/shadow the physical bundle; qualify Linux capture and shadow the
syscall bundle; qualify external adapters; lock `PTFP-Custom-v1`; run late
fusion; then activate read-only presentation.

## 10. Parameter Evidence Gate

Every executable v2 numeric parameter has a stable ID and one class:

- `direct`: stated by an authoritative source for the selected profile;
- `derived`: deterministic formula over sourced inputs;
- `measured`: preserved pilot or calibration result;
- `preregistered_factor`: research choice frozen before testing;
- `mock`: synthetic value scoped to a declared simulator/workload profile.

The record includes value, unit, class, source/decision ID, exact locator or
derivation, applicable profile, approval, and experiment scope. A citation does
not make all values in a document transferable.

No architecture default is created for noise, dynamics, divergence scaling,
trust thresholds, tolerances, fault size, windows, hyperparameters, anomaly
thresholds, queues, permitted capture loss, duration, repetitions, or fusion
weights. Missing provenance fails v2 startup. Legacy anonymous values remain
quarantined for reproduction only.

## 11. Verification Gates and Failure Semantics

| Gate | Required architecture evidence |
|---|---|
| G1 Provenance | All active values, sources, hashes, licenses, profiles, and v1 fixtures resolve. |
| G2 Signal v2 | Endpoint/round-trip/quality/profile/timestamp invariants pass end to end; no silent clipping. |
| G3 Consensus v2 | Deterministic Python/Go golden parity and versioned restart/query/state compatibility pass. |
| G4 Independent SCADA | Real client round trip preserves DataValue quality/time; causal separation matrix passes. |
| G5 Physical Bundle | Complete immutable bundle, inference-only runtime, mismatch failure, and declared-environment replay pass. |
| G6 Syscall Capture | Real edge attribution, ordering, loss/duplicates/gaps, overhead, backpressure, raw hash, and canonical replay are recorded. |
| G7 External Benchmarks | Version/split/schema/provenance pass for ADFA, LID, and HAI; labels remain evaluation-only. |
| G8 PTFP-Custom | Synchronized immutable runs and partitions pass; truth remains isolated; mixed/incomplete runs are flagged. |
| G9 Reproducible Result | Frozen scores/fusion join truth only after unlock; paired ablation rebuilds from manifests. |

Binding failure behavior:

- profile, schema, hash, bundle, or version mismatch fails closed;
- Python/Go mismatch keeps consensus v2 in shadow;
- invalid OPC evidence is reported, never replaced with consensus;
- syscall loss/attribution failure flags affected segments and follows the
  preregistered abort/exclusion policy; missing calls are never treated as
  normal behavior;
- truth leakage, mixed configurations, or post-unlock model changes abort the
  formal run;
- storage without verified persistence/restoration blocks formal campaigns;
- unknown HAI/ADFA/LID layouts are rejected;
- dashboard disagreement never overrides artifact/evaluator output.

Thresholds for measured gates are themselves direct, derived, measured, or
preregistered. This overlay invents no universal numeric acceptance value.

## 13. Final Position

The target architecture preserves engineering-domain simulator physics while
making the edge's raw electrical signal authoritative, captures real Linux
syscalls from identifiable controlled edge workloads, removes circular SCADA
evidence, isolates truth, freezes complete detector behavior, and permits only
late fusion on synchronized custom runs.

The dissertation claim remains an evidence-gated paired ablation: whether the
combination of calibrated physical and syscall evidence improves detection or
operational trade-offs over either modality alone for the declared custom
testbed. ADFA-LD, LID-DS, and HAI provide external context; they cannot replace
the synchronized evidence required for that conclusion.
