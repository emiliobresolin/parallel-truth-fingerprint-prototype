# Physical shadow serving and G5

`PhysicalShadowSelection.v1` binds an exact immutable physical bundle to its
profile, parameter set, feature schema/order through the bundle, preprocessing,
threshold, dependency lock, code/runtime, and a separate activity-authorization
identity. It accepts neither aliases nor a `latest` value.

The pure local route validates that closure before invoking an injected
inference adapter over validated `SignalObservation.v2` records. It never fits,
calibrates, learns, reads truth, promotes, controls, or writes an actuator.
Missing or incompatible prerequisites yield an explicit blocked/unavailable
result instead of a normal detector decision.

`G5PhysicalShadowQualification.v1` compares supplied frozen batch and shadow
scores, retaining mismatch identities. A failed result only blocks the new
selection or selects an explicitly supplied prior verified identity; it deletes
or rewrites no evidence. G5 therefore qualifies only this physical local shadow
path, never control, syscall capture, fusion, deployment, or UI work.
